
# Kernel and Non-Kernel Learning on Real-World Data

## Overview

This project compares kernel and non-kernel machine learning methods across four real-world datasets with different challenges such as missing values, outliers, class imbalance, nonlinear structure, and large-scale data.

The datasets include:

- Airbnb Open Data
- NYC 311 Service Requests
- IBM HR Employee Attrition
- Online Retail Transactions

## Main Topics

- Data Cleaning and Feature Engineering
- Missing Data and Outlier Analysis
- Class Imbalance Handling
- Logistic and Linear Regression
- K-Nearest Neighbors
- Decision Trees
- Kernel SVM
- Kernel Ridge Regression
- Kernel KNN
- Kernel PCA
- Failure and Bias Analysis
- Computational Complexity

## Technologies

Python · NumPy · SciPy · Pandas · Matplotlib · Jupyter Notebook
